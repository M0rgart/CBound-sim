# Синтетические данные в стиле Cbonds

Набор **полностью искусственных** данных облигационного рынка, стилизованный под
выгрузки Cbonds: эмитенты, выпуски, купонные графики, дневные котировки,
индексы и рейтинговые события.

> ⚠️ Данные не являются реальными котировками Cbonds или МосБиржи. Названия
> эмитентов вымышлены, ISIN сгенерированы. Набор предназначен для разработки,
> тестирования аналитики, обучения моделей и демонстраций.

## Состав

| Файл | Содержимое | Строк (seed 42) |
|---|---|---|
| `issuers.csv` | Справочник эмитентов | 56 |
| `bonds.csv` | Выпуски и метрики на дату оценки (30.12.2024) | 360 |
| `prices_daily.csv` | Дневные котировки за 2024 год | ~75 000 |
| `coupons.csv` | Купонные графики | ~4 000 |
| `indices_daily.csv` | Индексы (PI и TR) | 1 300 |
| `rating_events.csv` | Рейтинговые действия и дефолты | 90 |

Формат: CSV, **UTF-8 с BOM**, разделитель `;`, десятичная точка — открывается
в Excel двойным щелчком без настройки импорта.

## Как устроена модель

1. **Кривая бескупонной доходности** — Nelson–Siegel отдельно для RUB, USD, CNY.
   Параметры линейно интерполируются между началом и концом 2024 года и
   колеблются OU-процессом:
   - RUB: короткий конец ~15,6% → ~21,8% (рост ключевой ставки), длинный ~11,7% → ~13,8%;
   - USD: ~4,5–4,7%; CNY: ~2,6–2,7%.
2. **Кредитный спред** = базовый спред рейтинга + отраслевая поправка
   (+30 б.п. для валютных выпусков). Плюс индивидуальный OU-шум ~25 б.п.
3. **Цена** считается дисконтированием денежного потока по доходности с учётом
   частоты купона; НКД — по фактическому числу дней с последней выплаты.
   Для флоатеров цена держится около номинала, дюрация — до следующего купона.
4. **Обороты** — логнормальное распределение, масштабируются объёмом выпуска.
5. **Индексы** — ежедневная капитализация взвешенных доходностей; PI по чистым
   ценам, TR — с учётом купонных выплат.
6. **Рейтинговые события** — независимые случайные действия с перекосом
   в сторону подтверждений (60%) и понижений (22%).

## Запуск

```sh
py -3 cbonds_sim/generate_cbonds_sim.py --out cbonds_sim/data
py -3 cbonds_sim/generate_cbonds_sim.py --out data --seed 7 --bonds 500 --issuers 80
```

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `--out` | `data` | Каталог для CSV |
| `--seed` | `42` | Зерно генератора (детерминированность) |
| `--issuers` | `55` | Число эмитентов (без ОФЗ) |
| `--bonds` | `360` | Число выпусков (включая 10 ОФЗ) |

Только стандартная библиотека Python 3.9+, зависимостей нет.

## Ограничения

- Нет истории до 2024 года, кризисных сценариев и структурных разрывов.
- Амортизация номинала помечена флагом, но в цене не моделируется.
- Нет данных по сделкам (тик-дата), только дневные агрегаты.
- Оферты не влияют на дюрацию (кроме статуса и небольшой премии к спреду).
- ISIN синтетические и не проходят проверку контрольной цифры.
